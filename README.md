One original fortune for a houseplant, written for the
[Fortune in a Pot bounty on make.fun](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9):

> This week the sun will find your favorite leaf in the window, and your keeper will photograph you like a proud parent.

The line is a single prediction in fortune shape: "This week ... will ..."
gives it the cadence of a fortune being told, "your favorite leaf in the
window" pins it to the plant on this windowsill rather than any plant in
any room, and the joke — the keeper photographing the plant like a proud
parent — is the small, true laugh of a plant lover, with no pun, no doom,
and no care instruction in it.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the fortune to `out/entry.txt` (or `/output/entry.txt` in the
grader's sandbox). Node 22, standard library only, no dependencies, no
network, no model calls. Deterministic: the same bytes on every run.
